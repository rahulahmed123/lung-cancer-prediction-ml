# 🫁 Lung Cancer Prediction using Machine Learning

A machine learning-based lung cancer risk prediction system built with Python and deployed using Streamlit.

The project uses demographic, lifestyle, and symptom-related features to predict the likelihood of lung cancer. In addition to the prediction, the application provides input-based suggestions to help users understand relevant risk factors.

> ⚠️ **Disclaimer:** This project is developed for educational and research purposes only. It is not a medical diagnostic tool and should not replace professional medical advice.

## 📌 Project Overview

Lung cancer is one of the major causes of cancer-related mortality worldwide. Identifying potential risk factors and patterns in health-related data can help support early awareness and encourage timely medical evaluation.

This project explores the application of machine learning to structured health-related data as a binary classification problem.

### Main Objectives

- Perform data cleaning and preprocessing
- Conduct exploratory data analysis (EDA)
- Analyze feature relationships and distributions
- Encode categorical and binary features
- Apply appropriate feature scaling
- Train and compare machine learning models
- Use cross-validation for reliable model evaluation
- Select a suitable final model
- Create a deployment-friendly model artifact
- Build an interactive Streamlit application
- Provide input-based suggestions alongside predictions

# 🫁 Lung Cancer Prediction using Machine Learning

A machine learning-based lung cancer risk prediction system built with Python and deployed using Streamlit.

The project uses patient-related demographic, lifestyle, and symptom features to predict the likelihood of lung cancer and provides input-based suggestions to help users understand relevant risk factors.

> ⚠️ **Disclaimer:** This project is developed for educational and research purposes only. It is not a medical diagnostic tool and should not replace professional medical advice.

---

## 🚀 Live Application

The model is deployed as an interactive Streamlit web application.

Users can enter patient information through the web interface and receive:

- Lung cancer risk prediction
- Predicted probability
- Input-based personalized suggestions
- Risk-factor awareness

---

## 📌 Project Overview

Lung cancer is one of the major causes of cancer-related mortality worldwide. Early identification of potential risk factors can help encourage timely medical evaluation.

This project explores how machine learning can be applied to structured health-related data to build a binary classification system for lung cancer prediction.

### Main Objectives

- Perform data preprocessing and exploratory analysis
- Prepare features for machine learning
- Train and evaluate multiple classification models
- Select a suitable final model
- Save the trained model in a deployment-friendly format
- Build an interactive Streamlit application
- Generate input-based suggestions alongside predictions
